# Linden 1.0.0 validation

Validation date: 2026-10-05.

## Interactive Agent history checks

The development snapshot was tested through the global `linden` terminal CLI
and attached Pi UI using the locally configured `openai-codex/gpt-6-luna` model.
Model prompts were entered by keyboard, without a scripted request driver.

The checks passed for independent named-branch contexts, branch creation and
switching, current-branch rewind, branch head labels in tree/log views, native
optional summaries, exact user-message selection without a summary, and branch
persistence after workspace reopening. Temporary credential copies were removed.
These checks used the same product source imported into this release.

A related regression run passed 146 tests before release preparation. A separate
native Pi/Linden transport investigation reproduced socket-closure errors before
response headers and during SSE streaming; it does not establish a provider fix.
Raw transcripts, session identities, credential configurations, and experiment
records are retained only in the local research checkout.

## Standalone release checks

The standalone release worktree passed:

- `npm ci --offline --no-audit --no-fund`: independent dependency installation.
- `npm run check`: strict TypeScript checking.
- `npm test`: 297 passed, 0 failed, 0 skipped, including actual Linux/WSL sandbox,
  Term, and Net publication tests.
- `npm run build`: static native Term supervisor and TypeScript product build.
- Product source hash comparison with the selected development snapshot.
- Review of excluded research paths and public README/changelog links.

The first full-suite run exposed an outdated empty-Agent-log expectation. It was
updated to include the new branch metadata on both development and release;
no runtime behavior was changed for this correction.

Product source provenance: local development commit `d9b5eb31d3263ddc9e884afcfb9bb2d07ca0663e`.
The public release descends only from initial product commit
`d422a509e9d9ccaab22699b444a0d0f097e8ce6d`; the local development history is not
merged into that ancestry.

## Standalone terminal smoke test

The built release CLI was started from a separate temporary working directory,
using its own dependency installation and built supervisor. Commands were typed
into a real terminal, rather than dispatched through a scripted SDK. The checks
passed for startup, participant permissions, sandboxed Bash File write/read,
Term execution and durable logs (`TERM-OK`, exit code 0), an attached Agent with
explicit `gpt-6-luna` selection (`RELEASE-OK`), branch creation/switching, and
workspace archive/reopen. Reopening retained both branch heads and the model
reply, with Agent and Term participants stopped. The test workspace was archived
again and temporary credential copies were removed.

The four internal design/theory documents are excluded from the product branch
and its release history; only English release/validation documents are shipped
under `doc/`. No runtime source changed during this documentation cleanup.
